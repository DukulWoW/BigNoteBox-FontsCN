# BigNoteBox Fonts CN v1.0.1

## Change
- Fonts now also register with LibSharedMedia-3.0, so other addons (BigChatBox, WeakAuras, etc.) can use them too

# BigNoteBox Fonts CN v1.0.0

## New
- First release: six Chinese fonts for BigNoteBox's font picker - WenKai SC, Noto Sans SC, Grin Sans SC, ZCOOL KuaiLe, Ma Shan Zheng and Noto Serif SC
- Requires BigNoteBox 1.9.0 or newer, with BigNoteBox's language set to Simplified Chinese
