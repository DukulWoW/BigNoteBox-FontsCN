# BigNoteBox Fonts CN

Chinese (Simplified) font pack for [BigNoteBox](https://www.curseforge.com/wow/addons/bignotebox).
Adds six extra fonts to BigNoteBox's font picker for the `zhCN` client, so Chinese
users get more choice than WoW's own bundled Hei/Kai fonts.

Requires BigNoteBox. Install both, log in, pick a font on BigNoteBox's General tab.

## Fonts

| Font | Source | License |
|---|---|---|
| LXGW WenKai | [lxgw/LxgwWenKai](https://github.com/lxgw/LxgwWenKai) | OFL 1.1 |
| Noto Sans SC | [Google Fonts](https://fonts.google.com/noto/specimen/Noto+Sans+SC) | OFL 1.1 |
| Smiley Sans | [atelier-anchor/smiley-sans](https://github.com/atelier-anchor/smiley-sans) | OFL 1.1 |
| ZCOOL KuaiLe | [Google Fonts](https://fonts.google.com/specimen/ZCOOL+KuaiLe) | OFL 1.1 |
| Ma Shan Zheng | [Google Fonts](https://fonts.google.com/specimen/Ma+Shan+Zheng) | OFL 1.1 |
| Noto Serif SC | [Google Fonts](https://fonts.google.com/noto/specimen/Noto+Serif+SC) | OFL 1.1 |

Each font is subsetted to GBK or GB2312 coverage (see `Licenses/` for the exact
terms per font) to keep the pack's download size down. LXGW WenKai's subset was
renamed internally from its Reserved Font Name to stay OFL-compliant; see the
comment above its entry in `Fonts.lua`.
